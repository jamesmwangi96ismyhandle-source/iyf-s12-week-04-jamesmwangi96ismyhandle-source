# IYF Week 04 – JavaScript Fundamentals

**Repository:** `iyf-s12-week-04-jamesmwangi96ismyhandle-source`

## Project Description

This project demonstrates my understanding of JavaScript fundamentals through practical exercises, a calculator, a grade tracker and five daily coding challenges.

## Learning Objectives

- JavaScript variables using `let` and `const`
- Data types and operators
- Functions and arrow functions
- Conditional statements and loops
- Arrays and array methods
- Objects and JSON
- Array methods including `map()`, `filter()`, `reduce()`, `find()` and `sort()`

## How to Run

This project uses Node.js to execute JavaScript files.

Run the following commands in your terminal:

```bash
node main.js
node calculator.js
node grade-tracker.js
node test.js
```

Run individual daily challenges:

```bash
node daily-challenges/fizzbuzz.js
node daily-challenges/reverse-string.js
node daily-challenges/largest-number.js
node daily-challenges/remove-duplicates.js
node daily-challenges/palindrome.js
```

## Daily Challenges

1. FizzBuzz
2. Reverse a String
3. Find the Largest Number
4. Remove Duplicates from an Array
5. Palindrome Checker
